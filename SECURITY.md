# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Purrl, please open a private report via GitHub's Security Advisories (https://github.com/rbc33/Purrl/security/advisories/new) instead of a public issue.

Purrl has no network code and does not collect any data — see the README for details on what Accessibility permission is used for.

## Supported Versions

Only the latest released version is supported with fixes.
